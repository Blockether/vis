# Product

## Register

product

## Users

Software developers working in terminal-first coding workflows who need a durable coding agent that can inspect and change real projects without losing working state to the context window.

## Product Purpose

Vis provides a reliable, long-lived coding workspace across terminal and companion clients. Success means developers can move quickly between sessions, understand what the agent is doing, interrupt it safely, and continue work without UI or connection state getting in the way.

## Brand Personality

Direct, capable, and calm. The interface should feel like a dependable developer tool: information-dense where useful, restrained elsewhere, and never theatrical.

## Anti-references

Decorative or orchestrated motion, delayed navigation, unstable layouts, novelty controls, opaque status, and visual effects that compete with the developer's work.

## Design Principles

- Keep the developer in flow; navigation and interruption must feel immediate.
- Make system state legible without demanding attention.
- Prefer stable, familiar interaction over decorative novelty.
- Preserve continuity across sessions, clients, and long-running work.
- Spend complexity behind the interface, not in front of the user.

## Accessibility & Inclusion

Support keyboard-first operation, readable high-contrast themes, color-independent status cues, predictable focus and layout, and an animation-free experience by default rather than requiring a reduced-motion opt-out.
