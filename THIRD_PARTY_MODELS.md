# Third-party models

Vis uses third-party models for speech and decisions. This table lists
their licenses, authors and download sources.

This file is generated from `resources/vis-models/manifest.edn` and
`resources/vis-models/decisions.json`. Edit the manifests, then run
`vis-agent speech models licenses --markdown > THIRD_PARTY_MODELS.md`. Tests check that the document matches the manifest.

## `pocket-tts-int8`

Engine `:pocket-tts` - CC-BY-4.0 - commercial use permitted - hosted by Vis

pocket-tts by Kyutai (https://huggingface.co/kyutai/pocket-tts), CC BY 4.0, checkpoint b6369a24. ONNX export by the Vis project (bin/export-pocket-tts), published under the same terms with attribution to Kyutai. Reference clips generated by Vis (bin/make-voice-clips) from the public-domain Piper voices of Bryce Beattie (https://brycebeattie.com/files/tts/).

> Three reference clips ship with this bundle, all generated by Vis from public-domain voices. Pocket speaks by cloning such a clip, so any recording can become a voice: `vis-agent speech import <clip.wav> --name <name>`, or POST it to the gateway at /speech/voices. Imported clips stay on the machine that imported them.

- Upstream: <https://huggingface.co/kyutai/pocket-tts>
- Voices: Kristin (en-US), Cori (en-GB), John (en-US)
- Installs into: `~/.vis/models/sherpa-onnx-pocket-tts-int8`
- Downloaded from, in order:
  - the Vis assets release, 96 MB - <https://github.com/Blockether/vis/releases/download/assets-pack/pocket-tts-onnx.tar.bz2>

Piper uses eSpeak NG phoneme data under GPL-3.0-or-later. Each publisher archive includes
